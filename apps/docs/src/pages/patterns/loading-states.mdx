# Loading State Patterns

Arch provides three loading components for different scenarios:

| Component      | Type           | Use when                                          |
|----------------|----------------|---------------------------------------------------|
| `Spinner`      | Indeterminate  | Duration is unknown, compact space                |
| `ProgressBar`  | Determinate    | Progress percentage is known (uploads, steps)     |
| `Skeleton`     | Placeholder    | Content shape is known, replacing layout sections  |

## When to Use Each

**Spinner** -- Use for short, unpredictable operations: saving a form, fetching a small API response, or loading a dropdown's options. Spinners work well inline (inside buttons) or centered in a container.

**ProgressBar** -- Use when you can report a percentage: file uploads, multi-step wizards, or batch processing. The determinate value gives users a sense of time remaining.

**Skeleton** -- Use when the page layout is known but content has not loaded yet. Skeletons reduce perceived load time by showing the shape of incoming content rather than a blank space.

## Page-Level Loading

Center a `Spinner` with an accessible label when the entire page is loading:

```jsx
import { Spinner, Box } from '@arch-ui/components';

function PageLoading() {
  return (
    <Box
      className="page-loading"
      style={{
        display: 'flex',
        justifyContent: 'center',
        alignItems: 'center',
        minHeight: '50vh',
      }}
    >
      <Spinner size="lg" aria-label="Loading page content" />
    </Box>
  );
}
```

The `Spinner` renders with `role="status"` so screen readers announce the loading state.

## Inline Loading (Button)

Use the `loading` and `loadingText` props on `Button` to show a spinner inside the button and disable interaction:

```jsx
import { Button } from '@arch-ui/components';

function SaveButton({ isSaving, onSave }) {
  return (
    <Button
      kind="primary"
      isLoading={isSaving}
      loadingText="Saving..."
      onClick={onSave}
    >
      Save changes
    </Button>
  );
}
```

When `loading` is true, the button sets `aria-busy="true"` and renders a `Spinner` alongside the `loadingText`.

## Small Inline Spinner

For loading indicators inside other components (e.g. a search field or table cell), use a small spinner:

```jsx
import { Spinner, Inline } from '@arch-ui/components';

<Inline gap="var(--spacing-2)" align="center">
  <Spinner size="xs" aria-label="Loading results" />
  <span>Searching...</span>
</Inline>
```

## Determinate Progress

Use `ProgressBar` when you can track completion percentage. Always provide a `label` for screen readers:

```jsx
import { ProgressBar, Stack, Paragraph } from '@arch-ui/components';

function FileUpload({ progress }) {
  return (
    <Stack gap="var(--spacing-2)">
      <Paragraph>Uploading document... {progress}%</Paragraph>
      <ProgressBar value={progress} label="Upload progress" />
    </Stack>
  );
}
```

The component renders `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` attributes.

### Indeterminate Progress Bar

When the operation has no measurable progress but you want a linear indicator instead of a spinner:

```jsx
<ProgressBar indeterminate label="Processing your request" />
```

## Content Skeleton

Use `Skeleton` to match the shape of content that is loading. Set `aria-busy="true"` on the parent container so screen readers know content is pending.

### Card skeleton

```jsx
import { Skeleton, Stack, Box } from '@arch-ui/components';

function CardSkeleton() {
  return (
    <Box aria-busy="true">
      <Stack gap="var(--spacing-3)">
        {/* Avatar */}
        <Skeleton variant="circular" width="40px" />
        {/* Title */}
        <Skeleton variant="text" width="60%" />
        {/* Body lines */}
        <Skeleton variant="text" width="100%" />
        <Skeleton variant="text" width="100%" />
        <Skeleton variant="text" width="80%" />
        {/* Image placeholder */}
        <Skeleton variant="rectangular" width="100%" height="200px" />
      </Stack>
    </Box>
  );
}
```

### Table skeleton

Replace table rows with skeleton placeholders while data loads:

```jsx
import { Skeleton, Table, Thead, Tbody, Tr, Th, Td } from '@arch-ui/components';

function TableSkeleton({ rows = 5, columns = 4 }) {
  return (
    <Table caption="Loading data" aria-busy="true">
      <Thead>
        <Tr>
          {Array.from({ length: columns }).map((_, i) => (
            <Th key={i} scope="col">
              <Skeleton variant="text" width="80%" />
            </Th>
          ))}
        </Tr>
      </Thead>
      <Tbody>
        {Array.from({ length: rows }).map((_, row) => (
          <Tr key={row}>
            {Array.from({ length: columns }).map((_, col) => (
              <Td key={col}>
                <Skeleton variant="text" />
              </Td>
            ))}
          </Tr>
        ))}
      </Tbody>
    </Table>
  );
}
```

## Skeleton Variants

| Variant       | Shape                    | Typical use                |
|---------------|--------------------------|----------------------------|
| `text`        | Rounded rectangle, 1em tall | Text lines, labels       |
| `circular`    | Circle                   | Avatars, icons             |
| `rectangular` | Rectangle                | Images, cards, charts      |

## Reduced Motion

All three components respect `prefers-reduced-motion`:

- **Spinner**: Animation stops; a static partial ring is displayed.
- **ProgressBar**: The indeterminate animation stops; the bar remains visible.
- **Skeleton**: The shimmer animation stops; a static placeholder is shown.

## Accessibility Checklist

- `Spinner` has `role="status"` and requires `aria-label`.
- `ProgressBar` has `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`.
- `Skeleton` is `aria-hidden="true"` -- pair it with `aria-busy="true"` on the parent container.
- Buttons with `loading` set `aria-busy="true"` automatically.
- Do not rely solely on animation to communicate loading state -- always include text or ARIA labels.

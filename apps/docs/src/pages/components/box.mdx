# Box

<span class="status-badge status-badge--stable">stable</span>

Generic container with token-based styling props. Foundation of every other component's layout. Maps props directly to CSS custom properties.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `padding` | `string` | `—` | Spacing token name for all sides padding (e.g. 'spacing-component-md') |
| `paddingX` | `string` | `—` | Spacing token for inline (horizontal) padding |
| `paddingY` | `string` | `—` | Spacing token for block (vertical) padding |
| `margin` | `string` | `—` | Spacing token name for all sides margin |
| `marginX` | `string` | `—` | Spacing token for inline (horizontal) margin |
| `marginY` | `string` | `—` | Spacing token for block (vertical) margin |
| `background` | `string` | `—` | Color token name for background (e.g. 'color-surface-raised') |
| `border` | `string` | `—` | Color token name for border color |
| `radius` | `string` | `—` | Radius token name (e.g. 'radius-component-md') |
| `shadow` | `string` | `—` | Shadow token name (e.g. 'shadow-component-sm') |
| `as` | `React.ElementType` | `div` | HTML element to render. Default: 'div'. |
| `children` | `React.ReactNode` | `—` | Content to render inside the box |

## Usage Guidelines

**Do:**

- Use Box as the base container for layout composition
- Pass semantic token names as prop values
- Use paddingX/paddingY for directional padding (maps to CSS logical properties)

**Don't:**

- Do not pass raw CSS values — only token names
- Do not use Box for visual components — use specific components instead
- Do not nest Boxes deeply when Stack or Inline would be clearer

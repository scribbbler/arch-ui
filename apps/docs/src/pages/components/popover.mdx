# Popover

<span class="status-badge status-badge--stable">stable</span>

An interactive overlay panel triggered by clicking a reference element. Closes on Escape and outside click. Manages focus on open and close. Rendered via Portal with a transparent Overlay for click-outside detection.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `content` | `ReactNode` | `—` | The interactive content rendered inside the popover panel. |
| `position` | `'top' \| 'bottom' \| 'start' \| 'end'` | `bottom` | Preferred position of the popover relative to the trigger. |
| `isOpen` | `boolean` | `—` | Controls whether the popover is visible. |
| `onClose` | `() =&gt; void` | `—` | Called when the popover should close (Escape, outside click). |
| `onOpen` | `() =&gt; void` | `—` | Called when the popover should open. Used with triggerType='hover' to control visibility. |
| `triggerType` | `'click' \| 'hover'` | `click` | How the popover is triggered. 'click' shows on click with an overlay for dismiss. 'hover' shows on mouse enter with configurable delays. |
| `showArrow` | `boolean` | `false` | When true, renders a small arrow element pointing toward the trigger. |
| `onMouseEnterDelay` | `number` | `200` | Delay in ms before showing the popover on mouse enter. Only applies when triggerType='hover'. |
| `onMouseLeaveDelay` | `number` | `200` | Delay in ms before hiding the popover on mouse leave. Only applies when triggerType='hover'. |
| `children` | `ReactElement` | `—` | The trigger element. Must be a single focusable React element. |
## Accessibility

**ARIA attributes:** `aria-expanded`, `aria-haspopup`, `aria-controls`

**Keyboard interaction:**

- Escape (close)
- Tab / Shift+Tab (cycle focus within)

**Notes:**

- On open, focus moves to the first focusable element inside the popover.
- On close, focus returns to the trigger element.
- The trigger receives aria-expanded and aria-haspopup='dialog'.
- FocusTrap is used to contain keyboard focus while the popover is open.

## Usage Guidelines

**Do:**

- Use Popover for rich interactive overlays such as date pickers, filter panels, and action menus.
- Always provide an onClose handler that sets isOpen to false.
- Ensure the trigger element is keyboard focusable.

**Don't:**

- Do not use Popover for purely informational content — use Tooltip instead.
- Do not nest Popover inside another Popover.

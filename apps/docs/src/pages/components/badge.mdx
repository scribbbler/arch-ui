# Badge

<span class="status-badge status-badge--stable">stable</span>

An inline label used to communicate status, count, or categorical information at a glance. Supports five semantic variants and two sizes. A dot mode renders a compact indicator without text.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `'neutral' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `neutral` | Controls the colour palette of the badge. Maps to feedback colour tokens, except neutral which uses muted background. |
| `size` | `'sm' \| 'md'` | `md` | Controls the padding and font size of the badge. |
| `dot` | `boolean` | `false` | When true, renders a small circular indicator instead of text content. Requires aria-label when children are absent. |
| `children` | `ReactNode` | `—` | Label content displayed inside the badge. |
| `className` | `string` | `undefined` | Additional CSS class names to apply to the root element. |
| `aria-label` | `string` | `undefined` | Required when dot=true and no children are provided, to give screen readers a textual description. |
## Accessibility

**Role:** `generic`

**ARIA attributes:** `aria-label`

**Notes:**

- When dot=true and no children are provided, aria-label is required to convey meaning to screen readers.
- The dot element is aria-hidden when children are present alongside it.
- Badge is a presentational element — do not rely on colour alone to convey information.

## Usage Guidelines

**Do:**

- Use badge to communicate status inline with related content.
- Provide aria-label when using dot=true without children.
- Pair badge with adjacent text so colour is not the only information carrier.

**Don't:**

- Do not use badge as a standalone interactive element.
- Do not use badge to replace a full notification system.
- Do not render dot=true without an aria-label and without children.

# Tooltip

<span class="status-badge status-badge--stable">stable</span>

Non-interactive supplementary content shown on hover and focus after a configurable delay. Rendered via Portal into document.body. Must not contain interactive elements.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `content` | `ReactNode` | `—` | The tooltip content. Must be non-interactive text or static elements. |
| `position` | `'top' \| 'bottom' \| 'start' \| 'end'` | `top` | Preferred position of the tooltip relative to the trigger. |
| `delay` | `number` | `300` | Milliseconds to wait before showing the tooltip after hover or focus. |
| `children` | `ReactElement` | `—` | The trigger element. Must be a single React element that can receive event handler props. |
## Accessibility

**Role:** `tooltip`

**ARIA attributes:** `aria-describedby`

**Keyboard interaction:**

- Tab (focus trigger to show)
- Escape (implicit — tooltip hides on blur)

**Notes:**

- The trigger element receives aria-describedby pointing to the tooltip id.
- The tooltip element has role='tooltip'.
- Tooltip must NOT contain buttons, links, or any interactive content.
- Tooltip hides immediately on blur or mouse-leave; no delay on hide.
- Tooltip is rendered in a Portal to avoid clipping by overflow:hidden ancestors.

## Usage Guidelines

**Do:**

- Use tooltips to supplement icon buttons with a text label.
- Keep tooltip content concise — one sentence or less.
- Ensure the trigger element is keyboard focusable so tooltip content is accessible to keyboard users.

**Don't:**

- Do not put interactive elements (links, buttons) inside a tooltip.
- Do not use tooltips as the only way to convey essential information.
- Do not use tooltips on disabled elements — screen readers may not reach them.

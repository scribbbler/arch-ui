# Avatar

<span class="status-badge status-badge--stable">stable</span>

Displays a user's profile image with an initials fallback when the image is unavailable or fails to load. Supports multiple sizes and two shapes.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `src` | `string` | `undefined` | URL of the avatar image. When absent or on load failure, initials are shown. |
| `name` | `string` | `—` | Full name of the person. Used as alt text for the image and as the source for initials. Required. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | `md` | Controls the rendered dimensions via CSS custom properties. |
| `shape` | `'circle' \| 'square'` | `circle` | Circle uses radius-component-full; square uses radius-component-md. |
| `className` | `string` | `undefined` | Additional CSS class names to apply to the root element. |
## Accessibility

**Role:** `img`

**ARIA attributes:** `alt`, `aria-label`

**Notes:**

- The img element uses the name prop as its alt text for screen reader identification.
- When rendering initials (no src or image error), the container has role=img and aria-label set to the name prop.
- Image load errors are handled via onError to fall back to initials gracefully.

## Usage Guidelines

**Do:**

- Always provide the name prop — it drives both the alt text and initials.
- Use circle shape for person-oriented contexts (profiles, comments).
- Use square shape for organisation or brand avatars.

**Don't:**

- Do not use avatar without the name prop.
- Do not rely on the image alone to identify a person — the initials fallback must be meaningful.
- Do not scale avatars with inline styles — use the size prop.

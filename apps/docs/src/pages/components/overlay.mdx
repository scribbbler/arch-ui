# Overlay

<span class="status-badge status-badge--stable">stable</span>

A fixed-position semi-transparent backdrop used behind modals, drawers, and popovers. Marked aria-hidden as it is purely decorative.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `transparent` | `boolean` | `false` | When true, the overlay background becomes fully transparent. Useful for popovers that need click-outside behaviour without a visible backdrop. |
| `onClick` | `() =&gt; void` | `undefined` | Handler called when the backdrop is clicked. Used by parent components to close themselves. |
| `className` | `string` | `undefined` | Additional CSS class names applied to the overlay element. |
## Accessibility

**ARIA attributes:** `aria-hidden`

**Notes:**

- Always renders with aria-hidden='true' — it is a decorative backdrop.
- Accessible labels and focus management are the responsibility of the containing dialog component.
- The onClick handler enables closing parent components when the user clicks the backdrop.

## Usage Guidelines

**Do:**

- Always place Overlay behind the focused dialog content in the z-index stack.
- Use the transparent variant when you need click-outside detection without a dimming effect.

**Don't:**

- Do not place interactive content inside the Overlay element.
- Do not rely on Overlay for scroll locking — that is the dialog component's responsibility.

## Tokens Used

- `var(--color-background-overlay)`
- `var(--z-semantic-overlay)`

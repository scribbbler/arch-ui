# Heading

<span class="status-badge status-badge--stable">stable</span>

Semantic heading component rendering h1-h6 with independent typographic sizing. Level controls HTML semantics; size controls visual appearance from the heading scale.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `1` | Semantic heading level. Controls the rendered HTML element (h1-h6). Does not control visual size. |
| `size` | `'xxlarge' \| 'xlarge' \| 'large' \| 'medium' \| 'small' \| 'xsmall'` | `—` | Visual typography scale size. Independent of level. Defaults follow convention: level 1 → xxlarge, 2 → xlarge, 3 → large, 4 → medium, 5 → small, 6 → xsmall. |
| `weight` | `'semibold' \| 'bold' \| 'extrabold'` | `bold` | Font weight. Maps to typography-weight-* tokens. |
| `color` | `string` | `color-text-default` | Semantic text color token name (e.g. 'color-text-default'). Must be a valid design system token. |
| `children` | `React.ReactNode` | `—` | Heading content. |
| `className` | `string` | `—` | Additional CSS class names. |

## Usage Guidelines

**Do:**

- Use Heading for page and section titles
- Always choose a level that reflects document outline order — do not skip heading levels
- Use the size prop to achieve the desired visual scale independently of document structure
- Pass semantic token names as the color prop value

**Don't:**

- Do not use Heading for body text — use the Text component instead
- Do not choose a heading level for its visual size — adjust size prop instead
- Do not pass raw CSS values as color

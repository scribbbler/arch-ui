# Select

<span class="status-badge status-badge--stable">stable</span>

A native &lt;select&gt; element styled consistently with the Input component. Uses a custom chevron via CSS background-image to replace the browser default arrow. Integrates with FormControl context to receive id, disabled, required, and invalid state automatically.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `'sm' \| 'md' \| 'lg'` | `md` | Controls the select height, padding, and font size. md and lg meet the 44px minimum touch target. |
| `placeholder` | `string` | `undefined` | Inserts a disabled, empty-value &lt;option&gt; as the first item to act as a placeholder prompt. |
| `multiple` | `boolean` | `false` | Enables multi-select mode. The browser renders a listbox instead of a dropdown. |
| `disabled` | `boolean` | `false` | Disables the select. Also inherited from FormControl context if not explicitly set. |
| `isError` | `boolean` | `false` | Explicitly puts the select into an error visual state. Also triggered when FormControl invalid is true. |
| `children` | `ReactNode` | `undefined` | &lt;option&gt; and &lt;optgroup&gt; elements rendered inside the select. |
| `className` | `string` | `undefined` | Additional CSS class names applied to the wrapper div. |
## Accessibility

**Role:** `combobox`

**ARIA attributes:** `aria-required`, `aria-disabled`, `aria-invalid`, `aria-describedby`

**Keyboard interaction:**

- Tab
- Shift+Tab
- ArrowUp
- ArrowDown
- Space
- Enter

**Notes:**

- Uses a native &lt;select&gt; — keyboard navigation and screen reader announcements are handled by the browser/OS.
- When used inside a FormControl, the select id is set to the context id so the FormLabel htmlFor links correctly.
- aria-describedby is automatically built from '&#123;id&#125;-helper' and/or '&#123;id&#125;-error' when inside a FormControl.
- aria-invalid is set when the FormControl is invalid or isError prop is true.
- Focus indicator uses a 2px solid outline with var(--color-border-focus) and a 2px offset.
- Minimum touch target for md and lg sizes meets the 44x44px requirement.

## Usage Guidelines

**Do:**

- Always pair with a FormLabel (via FormControl) to provide an accessible name.
- Provide a placeholder option for fields where no initial selection should be implied.
- Use isError or FormControl invalid prop to signal validation failures.

**Don't:**

- Do not use for more than ~10 options without considering a searchable combobox instead.
- Do not use multiple unless the interface clearly communicates that multi-selection is available.
- Do not omit a label — if a visible label is not possible, provide aria-label directly on the Select.

# Display

<span class="status-badge status-badge--stable">stable</span>

Large display text for hero sections, marketing pages, and visual emphasis. Not a semantic heading — use Heading for document structure. Display is purely visual.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `'display-2xl' \| 'display-xl' \| 'display-lg' \| 'display-md' \| 'display-sm'` | `display-lg` | Typography scale size |
| `weight` | `'semibold' \| 'bold' \| 'extrabold'` | `bold` | Font weight |
| `color` | `string` | `color-text-default` | Semantic text color token name |
| `as` | `React.ElementType` | `p` | HTML element to render. Default: 'p'. Use Heading for semantic h1-h6. |
| `children` | `React.ReactNode` | `—` |  |
## Usage Guidelines

**Do:**

- Use Display for hero text, marketing headlines, and large visual emphasis
- Pair with Heading when you need both visual size and semantic heading level

**Don't:**

- Do not use Display for document headings — use Heading for h1-h6 semantics
- Do not use Display for body text — use Paragraph

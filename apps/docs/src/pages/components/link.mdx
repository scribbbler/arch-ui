# Link

<span class="status-badge status-badge--stable">stable</span>

Anchor element with token-based color variants and accessibility-aware external link handling. Provides :focus-visible styling and distinct visited/hover states.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `href` | `string` | `—` | The URL the link points to. |
| `external` | `boolean` | `false` | When true, appends ' (opens in new tab)' to aria-label for screen reader users. Does NOT automatically set target='_blank' — callers must do that explicitly. |
| `variant` | `'default' \| 'subtle' \| 'inverse'` | `default` | Color variant. 'default' uses color-text-link tokens. 'subtle' uses color-text-subtle. 'inverse' uses color-text-inverse. |
| `animateUnderline` | `boolean` | `false` | When true, the underline animates in from the left on hover instead of showing a static underline. |
| `children` | `React.ReactNode` | `—` | Link label content. |
| `className` | `string` | `—` | Additional CSS class names. |

## Usage Guidelines

**Do:**

- Always provide meaningful link text — avoid 'click here' or 'read more'
- Use external=true when the link opens content outside the current application
- Set target='_blank' explicitly alongside external=true when you want the link to open in a new tab
- Use variant='inverse' for links placed on dark or coloured backgrounds

**Don't:**

- Do not rely on external prop alone to open a new tab — set target='_blank' separately
- Do not use Link for actions — use a Button instead
- Do not suppress the visited state for navigation links

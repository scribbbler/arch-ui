# Slider

<span class="status-badge status-badge--stable">stable</span>

A range slider rendered as a native &lt;input type='range'&gt;. Styled track and thumb use CSS vendor-prefixed pseudo-elements. The filled portion hint uses color-action-primary. Keyboard arrow key interaction is provided natively by the browser.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | `undefined` | Current value. Use with onChange for controlled usage. |
| `defaultValue` | `number` | `undefined` | Initial value for uncontrolled usage. |
| `min` | `number` | `0` | Minimum allowed value. |
| `max` | `number` | `100` | Maximum allowed value. |
| `step` | `number` | `1` | Increment size for each step. |
| `onChange` | `(value: number) =&gt; void` | `undefined` | Callback fired with the numeric value when the slider changes. |
| `disabled` | `boolean` | `false` | Disables the slider. |
| `className` | `string` | `undefined` | Additional CSS class names applied to the wrapper div. |
## Accessibility

**Role:** `slider`

**ARIA attributes:** `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, `aria-disabled`, `aria-label`, `aria-labelledby`

**Keyboard interaction:**

- ArrowLeft / ArrowDown — decrease by step
- ArrowRight / ArrowUp — increase by step
- Home — jump to min
- End — jump to max
- Tab / Shift+Tab — focus management

**Notes:**

- aria-valuemin, aria-valuemax, and aria-valuenow are provided natively by the range input.
- Focus indicator uses a 2px solid outline with var(--color-border-focus) and a 2px offset.
- Disabled state reduces opacity and sets cursor: not-allowed.
- Thumb meets the 44x44px minimum touch target via min-block-size and min-inline-size.
- Always provide an accessible name via aria-label or by associating with a visible label.

## Usage Guidelines

**Do:**

- Always provide an accessible name via aria-label or a visible label element with htmlFor.
- Pair with a visible value display so users know the exact current value.
- Use step values that produce a clean set of options for the context (e.g., step=5 for percentages).

**Don't:**

- Do not use for precise numeric entry — use an Input type='number' instead or alongside.
- Do not omit a label — range inputs have no implicit accessible name.
- Do not rely on colour alone to communicate the filled portion.

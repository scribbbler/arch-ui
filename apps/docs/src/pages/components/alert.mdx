# Alert

<span class="status-badge status-badge--stable">stable</span>

An inline feedback message component that communicates status or important information to the user. Supports four semantic variants: info, success, warning, and danger.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `'info' \| 'success' \| 'warning' \| 'danger'` | `info` | Semantic variant controlling color and icon. |
| `title` | `string` | `undefined` | Bold heading text for the alert. |
| `description` | `string \| ReactNode` | `undefined` | Body content of the alert. |
| `onClose` | `() =&gt; void` | `undefined` | When provided, a dismiss button is rendered. |
| `icon` | `ReactNode` | `variant default icon` | Override the default variant icon. Pass null to suppress. |
| `labels` | `Partial&lt;AlertLabels&gt;` | `&#123; dismiss: 'Dismiss alert' &#125;` | Override default labels for internationalisation. AlertLabels: &#123; dismiss: string &#125;. |
| `className` | `string` | `undefined` | Additional CSS class names. |
## Accessibility

**Role:** `alert (danger/warning) or status (success/info)`

**ARIA attributes:** `role`

**Notes:**

- Danger and warning alerts use role='alert' (assertive, interrupts screen readers).
- Success and info alerts use role='status' (polite, waits for idle).
- When onClose is provided, a dismiss button is rendered with an accessible label.
- The icon is aria-hidden — decorative only.
- Title is bold and rendered as a strong element.

## Usage Guidelines

**Do:**

- Use 'danger' for errors or destructive consequences.
- Use 'warning' for non-critical cautions that require attention.
- Use 'success' for confirmations of completed actions.
- Use 'info' for neutral informational messages.
- Always include a title or description — never an empty alert.

**Don't:**

- Do not use Alert for transient notifications — use Toast instead.
- Do not use 'danger' for general information.
- Do not place multiple alerts on a page when one summary would suffice.

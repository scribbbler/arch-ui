# Button

<span class="status-badge status-badge--stable">stable</span>

A polymorphic button component supporting multiple variants, sizes, and states including loading. Always renders a &lt;button&gt; element by default, but accepts an `as` prop to render as any element type (e.g., an anchor for link-styled buttons).

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `'primary' \| 'secondary' \| 'ghost' \| 'destructive' \| 'link'` | `primary` | Visual style of the button. Maps directly to action color tokens. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `md` | Size of the button, controlling padding and font-size. xs is a compact size for dense UIs. |
| `shape` | `'default' \| 'pill' \| 'circle' \| 'square'` | `default` | Shape of the button. pill uses full radius. circle and square use equal aspect ratio (ideal for icon-only buttons). |
| `isSelected` | `boolean` | `false` | Indicates the button is in a selected/pressed state. Useful for toggle button groups. Sets aria-pressed. |
| `disabled` | `boolean` | `false` | Disables the button. Applies reduced opacity and prevents interaction. |
| `loading` | `boolean` | `false` | Shows a loading spinner and disables the button. Sets aria-busy=true. |
| `loadingText` | `string` | `undefined` | Optional text to display while loading. Replaces children visually and for screen readers. |
| `leftIcon` | `ReactNode` | `undefined` | Icon rendered to the inline-start of the label. |
| `rightIcon` | `ReactNode` | `undefined` | Icon rendered to the inline-end of the label. |
| `fullWidth` | `boolean` | `false` | When true, the button stretches to fill its container width. |
| `as` | `ElementType` | `button` | The HTML element or React component to render. Use 'a' for link-styled buttons. |
| `type` | `'button' \| 'submit' \| 'reset'` | `button` | The HTML button type attribute. Defaults to 'button' to avoid accidental form submissions. |
| `onClick` | `(event: React.MouseEvent) =&gt; void` | `undefined` | Click event handler. |
| `children` | `ReactNode` | `—` | Button label content. |
| `className` | `string` | `undefined` | Additional CSS class names to apply. |
## Accessibility

**Role:** `button`

**ARIA attributes:** `aria-disabled`, `aria-busy`

**Keyboard interaction:**

- Enter
- Space

**Notes:**

- When loading, aria-busy is set to true and the button is disabled.
- Disabled state uses both the disabled attribute and aria-disabled for maximum compatibility.
- Focus indicator uses a 2px outline with a 2px offset using var(--color-border-focus).
- When loadingText is provided, it replaces the visible label during loading for screen reader clarity.

## Usage Guidelines

**Do:**

- Use a single primary button per section or dialog.
- Provide loadingText when the loading state needs a descriptive label.
- Use the `as` prop with an anchor element when navigating, so keyboard and screen reader behaviour is correct.
- Pair leftIcon or rightIcon with concise label text.

**Don't:**

- Do not use more than one primary button in the same visual group.
- Do not disable a button without explaining why (use a tooltip or adjacent helper text).
- Do not use the link variant for navigation outside the current context — use a real anchor.
- Do not nest interactive elements inside a button.

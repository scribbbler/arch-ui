# Accordion

<span class="status-badge status-badge--stable">stable</span>

A vertically stacked set of interactive headings that expand or collapse associated content panels. Supports single or multiple open sections simultaneously.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` | `Array&lt;&#123; title: ReactNode; content: ReactNode; disabled?: boolean &#125;&gt;` | `—` | Array of accordion sections. Each item must have a title (string or ReactNode), content ReactNode, and an optional disabled flag. |
| `allowMultiple` | `boolean` | `false` | When true, multiple sections can be open simultaneously. |
| `defaultExpanded` | `number[]` | `[]` | Indices of sections that are expanded by default on first render. |
| `disabled` | `boolean` | `false` | When true, all accordion panels are disabled and cannot be toggled. |
| `onChange` | `(expandedItems: string[]) =&gt; void` | `—` | Called when the set of expanded items changes. Receives indices of expanded items as string array. |
| `className` | `string` | `undefined` | Additional CSS class names to apply to the root element. |
## Accessibility

**Role:** `none`

**ARIA attributes:** `aria-expanded`, `aria-controls`, `aria-labelledby`, `aria-disabled`

**Keyboard interaction:**

- Enter
- Space
- ArrowDown
- ArrowUp
- Home
- End

**Notes:**

- Each section header is a &lt;button&gt; element with aria-expanded and aria-controls.
- Each panel has role='region' and aria-labelledby pointing to its trigger button.
- Arrow keys move focus between header buttons.
- Home/End move focus to first/last header.
- Animation respects prefers-reduced-motion.

## Usage Guidelines

**Do:**

- Use for FAQs, settings panels, or any grouped content that benefits from progressive disclosure.
- Provide concise, descriptive titles for each section.
- Use allowMultiple when sections are independent and users may need to compare content.

**Don't:**

- Do not nest Accordions inside Accordion panels — use a flat structure.
- Do not use Accordion for navigation — use Tabs or a navigation menu instead.
- Do not place critical required information inside a collapsed section.

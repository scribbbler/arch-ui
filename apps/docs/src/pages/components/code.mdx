# Code

<span class="status-badge status-badge--stable">stable</span>

Renders inline code snippets or block-level code samples. Inline mode renders a &lt;code&gt; element; block mode renders a &lt;pre&gt;&lt;code&gt; structure. Uses the monospace font family and code typography scale tokens.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `block` | `boolean` | `false` | When true, renders as a block-level &lt;pre&gt;&lt;code&gt; element with background, padding, and border-radius. When false (default), renders as an inline &lt;code&gt; element. |
| `language` | `string` | `—` | Optional language hint for syntax identification (e.g. 'typescript', 'css'). Sets a data-language attribute. Does not perform syntax highlighting. |
| `size` | `'code-md' \| 'code-sm'` | `code-md` | Typography scale size. Maps to typography-scale-code-* tokens. |
| `children` | `React.ReactNode` | `—` | Code content. |
| `className` | `string` | `—` | Additional CSS class names. |

## Usage Guidelines

**Do:**

- Use block mode for multi-line code samples or code examples in documentation
- Use inline mode for referencing variable names, function names, or short snippets within prose
- Provide the language prop as a hint for tooling or future syntax highlighting integration

**Don't:**

- Do not use Code for decorative monospace text — use Text with a mono font if needed
- Do not nest block Code inside inline elements
- Do not use Code as a replacement for a full syntax highlighter in code-heavy UIs

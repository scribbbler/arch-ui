# Radio

<span class="status-badge status-badge--stable">stable</span>

A radio input component that renders a real &lt;input type="radio"&gt; for accessibility, with a custom-styled visual overlay. Must be used inside a RadioGroup, from which it reads name, selectedValue, onChange, and disabled via context.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | `—` | The value this radio represents. Compared against RadioGroup's value to determine selected state. |
| `disabled` | `boolean` | `false` | Disables this specific radio. Also disabled if the parent RadioGroup is disabled. |
| `children` | `ReactNode` | `—` | Label content rendered next to the radio circle. |
| `className` | `string` | `undefined` | Additional CSS class names for the wrapper element. |
## Accessibility

**Role:** `radio`

**ARIA attributes:** `aria-checked`, `aria-disabled`

**Keyboard interaction:**

- ArrowUp
- ArrowDown
- ArrowLeft
- ArrowRight

**Notes:**

- A real &lt;input type="radio"&gt; is rendered and visually hidden; the styled circle is a presentation layer.
- Must be used inside a RadioGroup which provides name, value, onChange, and disabled via context.
- Focus indicator appears on the visual circle via :focus-visible using var(--color-border-focus).
- Arrow key navigation is managed by the parent RadioGroup.
- The tab index follows ARIA radio group pattern: only the selected (or first) radio is in the tab order.

## Usage Guidelines

**Do:**

- Always use Radio inside a RadioGroup.
- Provide a unique value prop for each Radio in the group.
- Provide visible label text as children.

**Don't:**

- Do not use Radio outside of a RadioGroup.
- Do not use Radio for non-exclusive choices — use Checkbox instead.
- Do not leave a radio without a label.

# FileUpload

<span class="status-badge status-badge--stable">stable</span>

A file upload drop zone with drag-and-drop support. A visually styled &lt;label&gt; wraps a hidden &lt;input type='file'&gt;. Supports accept filtering, multiple files, max file size validation, and exposes drag states via CSS modifier classes.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `accept` | `string` | `undefined` | Comma-separated list of accepted file types (MIME types or extensions, e.g. 'image/*,.pdf'). Passed directly to the input's accept attribute. |
| `multiple` | `boolean` | `false` | Allows selecting multiple files at once. |
| `maxSize` | `number` | `undefined` | Maximum individual file size in bytes. Files exceeding this trigger the error state. |
| `disabled` | `boolean` | `false` | Disables the drop zone and prevents file selection. |
| `onDrop` | `(files: File[]) =&gt; void` | `undefined` | Callback fired when files are selected (via dialog or drag-and-drop) and pass validation. |
| `labels` | `Partial&lt;FileUploadLabels&gt;` | `&#123; fileSizeError: (count, limit) =&gt; `$&#123;count&#125; file(s) exceed(s) the $&#123;limit&#125; limit.` &#125;` | Override default labels for internationalisation. FileUploadLabels: &#123; fileSizeError: (count: number, limit: string) =&gt; string &#125;. |
| `progressMessage` | `string` | `undefined` | Text to display for upload progress (e.g. 'Uploading 3 of 5 files…'). Rendered as a role='status' element inside the drop zone. |
| `className` | `string` | `undefined` | Additional CSS class names applied to the root wrapper div. |
## Accessibility

**Role:** `presentation (label wraps input)`

**ARIA attributes:** `aria-disabled`, `aria-label`, `aria-labelledby`, `aria-describedby`

**Keyboard interaction:**

- Tab
- Shift+Tab
- Space / Enter — activate file dialog

**Notes:**

- The hidden &lt;input type='file'&gt; receives focus — screen readers announce it as a file upload button.
- The label's for/id association means clicking or activating the visible zone opens the file dialog.
- Disabled state hides the input from keyboard navigation and reduces visual opacity.
- Error state (file too large or wrong type) is communicated via role='alert' on the error message element.
- Focus indicator is applied to the hidden input via :focus-visible, with a visible outline on the drop zone.

## Usage Guidelines

**Do:**

- Provide descriptive children content explaining accepted file types and size limits.
- Show a file list after selection so users know what will be uploaded.
- Use the error state with a role='alert' message to explain why files were rejected.

**Don't:**

- Do not suppress the native file dialog — some users rely on it exclusively.
- Do not silently reject files — always communicate why a file was not accepted.
- Do not omit the accept prop if only specific file types are valid — it filters the OS file picker.

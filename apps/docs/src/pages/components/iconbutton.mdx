# IconButton

<span class="status-badge status-badge--stable">stable</span>

An icon-only button. Renders a square, accessible button that displays a single icon. Requires an `aria-label` prop to ensure screen reader users understand its purpose.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `aria-label` | `string` | `—` | Accessible name for the button. REQUIRED — must describe the action, not the icon shape. Example: 'Close dialog', not 'X icon'. |
| `icon` | `ReactNode` | `—` | The icon to display. Typically an SVG element or icon component. |
| `variant` | `'primary' \| 'secondary' \| 'ghost' \| 'destructive' \| 'link'` | `primary` | Visual style of the button. Maps directly to action color tokens. |
| `size` | `'sm' \| 'md' \| 'lg'` | `md` | Size of the button, controlling the square dimensions and icon size. |
| `disabled` | `boolean` | `false` | Disables the button. Applies reduced opacity and prevents interaction. |
| `loading` | `boolean` | `false` | Shows a loading spinner and disables the button. Sets aria-busy=true. |
| `className` | `string` | `undefined` | Additional CSS class names to apply. |
## Accessibility

**Role:** `button`

**ARIA attributes:** `aria-label`, `aria-disabled`, `aria-busy`

**Keyboard interaction:**

- Enter
- Space

**Notes:**

- aria-label is REQUIRED. A console error is logged in development if it is missing.
- When loading, aria-busy is set to true and the button is disabled.
- Focus indicator uses a 2px outline with a 2px offset using var(--color-border-focus).
- The icon itself is wrapped in an aria-hidden span so the label is the sole text alternative.

## Usage Guidelines

**Do:**

- Always provide a descriptive aria-label that describes the action performed.
- Use ghost variant for icon buttons in toolbars and dense UIs.
- Pair with a visible tooltip to reinforce the icon meaning.

**Don't:**

- Do not omit aria-label — this will cause an accessibility violation.
- Do not use aria-label values like 'icon' or 'button' — be specific about the action.
- Do not place text children inside IconButton — use Button instead.

# Label

<span class="status-badge status-badge--stable">stable</span>

UI text for interactive elements — form labels, button text, navigation items, badges, table headers. Medium or semibold weight by default. Not for body copy (use Paragraph) or headings (use Heading).

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `'large' \| 'medium' \| 'small' \| 'xsmall'` | `medium` | Label size. Maps to label scale tokens. |
| `weight` | `'medium' \| 'semibold' \| 'bold'` | `medium` | Font weight. Default: 'medium'. |
| `color` | `string` | `color-text-default` | Semantic text color token name |
| `uppercase` | `boolean` | `false` | Renders text in uppercase with wider letter-spacing. Useful for overlines and category labels. |
| `as` | `React.ElementType` | `span` | HTML element to render. Default: 'span'. |
| `children` | `React.ReactNode` | `—` |  |
## Usage Guidelines

**Do:**

- Use Label for button text, nav items, form labels, table headers, badge text
- Use uppercase=true for overlines and category labels
- Use size='xsmall' for fine print and metadata

**Don't:**

- Do not use Label for body copy — use Paragraph
- Do not use Label for page headings — use Heading or Display

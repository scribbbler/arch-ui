# VisuallyHidden

<span class="status-badge status-badge--stable">stable</span>

Hides content visually while keeping it accessible to screen readers. Used for icon labels, skip links, and supplementary context.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `as` | `React.ElementType` | `span` | HTML element to render. Default: 'span'. |
| `children` | `React.ReactNode` | `—` |  |

## Usage Guidelines

**Do:**

- Use VisuallyHidden to provide accessible labels for icon-only buttons
- Use inside form elements to add context for screen readers
- Use for skip navigation link text

**Don't:**

- Do not use to hide content that should be visible — it is only for a11y content
- Do not use display:none or visibility:hidden — those hide from screen readers too

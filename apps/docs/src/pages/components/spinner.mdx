# Spinner

<span class="status-badge status-badge--stable">stable</span>

A circular loading indicator that communicates an ongoing process. Respects prefers-reduced-motion by replacing the animation with a static circle. Uses role='status' and an accessible aria-label so screen readers announce the loading state.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `md` | Controls the diameter of the spinner. xs=16px, sm=20px, md=32px, lg=48px. |
| `aria-label` | `string` | `Loading` | Accessible label announced by screen readers. Override when context requires a more descriptive phrase such as 'Saving changes'. |
| `labels` | `Partial&lt;SpinnerLabels&gt;` | `&#123; loading: 'Loading' &#125;` | Override default labels for internationalisation. SpinnerLabels: &#123; loading: string &#125;. The labels.loading value is used as the aria-label default; an explicit aria-label prop takes precedence. |
| `className` | `string` | `undefined` | Additional CSS class names applied to the root element. |
## Accessibility

**Role:** `status`

**ARIA attributes:** `aria-label`

**Notes:**

- role='status' causes screen readers to announce the label without interrupting the user (live region with aria-live='polite').
- aria-label defaults to 'Loading' and must always be provided — either via the default or an explicit override.
- When prefers-reduced-motion is set the rotation animation is disabled and a static circle is shown instead.
- The element is not interactive and never receives focus.

## Usage Guidelines

**Do:**

- Always provide a meaningful aria-label when the default 'Loading' is not descriptive enough.
- Use the lg size for full-page loading and xs/sm inside buttons or tight containers.
- Pair with VisuallyHidden text if you need visible copy alongside the spinner.

**Don't:**

- Do not use a Spinner for progress that can be quantified — use ProgressBar instead.
- Do not apply inline styles — use the className prop and extend via CSS tokens.
- Do not suppress the aria-label — every Spinner must have an accessible name.

## Tokens Used

- `var(--color-action-primary)`
- `var(--color-background-muted)`
- `var(--motion-duration-slow)`
- `var(--motion-semantic-easing-default)`

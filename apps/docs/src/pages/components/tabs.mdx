# Tabs

<span class="status-badge status-badge--stable">stable</span>

A controlled tab component supporting horizontal and vertical orientations with two visual variants: line (bottom-border indicator) and enclosed (folder-tab style). Fully keyboard accessible with arrow-key navigation.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `tabs` | `Array&lt;&#123; label: string; value: string; content: ReactNode; disabled?: boolean; artwork?: ReactNode &#125;&gt;` | `—` | Array of tab definitions. Each item provides a label, a unique value, panel content, an optional disabled flag, and an optional artwork (icon) slot rendered before the label. |
| `activeValue` | `string` | `—` | The value of the currently active tab. This is a controlled prop — the parent must update it via onChange. |
| `onChange` | `(value: string) =&gt; void` | `—` | Called when the user activates a tab. Receives the tab's value string. |
| `variant` | `'line' \| 'enclosed'` | `line` | Visual style. 'line' shows a bottom border on the active tab. 'enclosed' renders tabs as folder-style raised cards. |
| `orientation` | `'horizontal' \| 'vertical'` | `horizontal` | Layout direction. Affects arrow-key navigation and visual layout. |
| `fill` | `'fixed' \| 'intrinsic'` | `intrinsic` | Tab width behaviour. 'intrinsic' sizes tabs to their content. 'fixed' makes all tabs equal width. |
| `renderAll` | `boolean` | `false` | When true, all tab panels are rendered in the DOM (inactive panels hidden with CSS) for SEO purposes. |
| `className` | `string` | `undefined` | Additional CSS class names to apply to the root element. |
## Accessibility

**Role:** `tablist`

**ARIA attributes:** `aria-selected`, `aria-controls`, `aria-labelledby`, `aria-disabled`, `aria-orientation`

**Keyboard interaction:**

- ArrowLeft / ArrowRight — navigate tabs in horizontal orientation
- ArrowUp / ArrowDown — navigate tabs in vertical orientation
- Home — move focus to first enabled tab
- End — move focus to last enabled tab
- Tab — move focus into the active tab panel

**Notes:**

- Disabled tabs have aria-disabled="true" and are skipped in arrow-key navigation.
- Each tab has a unique id and aria-controls pointing to its panel id.
- Each panel has role="tabpanel", tabIndex=0, and aria-labelledby pointing to its tab id.
- The tablist has aria-orientation matching the orientation prop.

## Usage Guidelines

**Do:**

- Use tabs to switch between parallel views of the same level of hierarchy.
- Keep tab labels short (1–3 words) so the tablist does not overflow.
- Provide an activeValue and onChange — this is a controlled component.
- Ensure each tab value is unique within the set.

**Don't:**

- Do not use tabs for sequential steps — use ProgressSteps instead.
- Do not nest tabs inside tabs.
- Do not disable all tabs simultaneously.
- Do not use more than 7 tabs in a single tablist.

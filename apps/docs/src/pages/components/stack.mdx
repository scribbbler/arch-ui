# Stack

<span class="status-badge status-badge--stable">stable</span>

Vertical flex layout with token-based gap. Children are stacked vertically with consistent spacing.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `gap` | `string` | `—` | Spacing token name for gap between children (e.g. 'spacing-component-md') |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `stretch` | Cross-axis alignment (maps to align-items) |
| `justify` | `'start' \| 'center' \| 'end' \| 'space-between'` | `start` | Main-axis alignment (maps to justify-content) |
| `direction` | `'column' \| 'column-reverse'` | `column` | Stack direction |
| `as` | `React.ElementType` | `div` | HTML element to render. Default: 'div'. |
| `children` | `React.ReactNode` | `—` |  |

## Usage Guidelines

**Do:**

- Use Stack for vertical layouts with consistent spacing
- Use gap prop with spacing tokens for consistent rhythm

**Don't:**

- Do not use Stack for horizontal layouts — use Inline instead
- Do not pass raw pixel values to gap — use token names

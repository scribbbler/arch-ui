# Drawer

<span class="status-badge status-badge--stable">stable</span>

A panel that slides in from a configurable side of the screen. Uses Portal, Overlay, and FocusTrap. Matches Modal ARIA patterns with role='dialog' and aria-modal='true'. Transition respects prefers-reduced-motion.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `isOpen` | `boolean` | `—` | Controls drawer visibility. |
| `onClose` | `() =&gt; void` | `—` | Called when the drawer should close. |
| `position` | `'start' \| 'end' \| 'top' \| 'bottom'` | `end` | Side from which the drawer slides in. Uses CSS logical properties for RTL support. |
| `size` | `string` | `20rem` | Inline-size (for start/end) or block-size (for top/bottom) of the drawer panel. |
| `animate` | `boolean` | `true` | When true, the drawer uses slide-in/out animations. Set to false for instant appearance. |
| `children` | `ReactNode` | `—` | Drawer content. |
## Accessibility

**Role:** `dialog`

**ARIA attributes:** `aria-modal`, `aria-label`

**Keyboard interaction:**

- Escape (close)
- Tab / Shift+Tab (cycle within)

**Notes:**

- role='dialog' and aria-modal='true' match the ARIA dialog pattern.
- Body scroll is locked while the drawer is open.
- Focus is trapped inside via FocusTrap and restored to the trigger on close.
- Transitions are disabled when prefers-reduced-motion: reduce is active.
- CSS logical properties (inset-inline-start/end, inset-block-start/end) ensure correct RTL behaviour.

## Usage Guidelines

**Do:**

- Use Drawer for navigation panels, filter sidebars, and detail views.
- Include a visible close button inside the drawer.
- Provide a concise aria-label when no visible heading is present.

**Don't:**

- Do not open a Drawer from inside a Modal.
- Do not rely on the Drawer for critical multi-step flows — use a Modal instead.

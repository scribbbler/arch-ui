# Modal

<span class="status-badge status-badge--stable">stable</span>

A full-overlay dialog component with scroll lock, focus management, and configurable size. Composed from Portal, Overlay, and FocusTrap. Includes ModalHeader, ModalBody, and ModalFooter sub-components.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `isOpen` | `boolean` | `—` | Controls modal visibility. |
| `onClose` | `() =&gt; void` | `—` | Called when the modal should close. |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `md` | Controls the max-width of the modal panel. |
| `closeOnOverlayClick` | `boolean` | `true` | When true, clicking the backdrop closes the modal. |
| `closeOnEscape` | `boolean` | `true` | When true, pressing Escape closes the modal. |
| `role` | `'dialog' \| 'alertdialog'` | `dialog` | ARIA role for the dialog element. Use 'alertdialog' for confirmation dialogs that require user acknowledgement. |
| `animate` | `boolean` | `true` | When true, the modal animates in on mount. Set to false for instant appearance. |
| `children` | `ReactNode` | `—` | Modal content. Typically composed of ModalHeader, ModalBody, and ModalFooter. |
## Accessibility

**Role:** `dialog | alertdialog`

**ARIA attributes:** `aria-modal`, `aria-labelledby`

**Keyboard interaction:**

- Escape (close, if closeOnEscape=true)
- Tab / Shift+Tab (cycle within)

**Notes:**

- role='dialog' and aria-modal='true' are set on the dialog element.
- aria-labelledby connects the dialog to ModalHeader's heading element.
- Body scroll is locked (overflow:hidden) while the modal is open.
- Focus is trapped inside via FocusTrap and restored to the trigger on close.
- Clicking the Overlay closes the modal when closeOnOverlayClick=true (default).

## Usage Guidelines

**Do:**

- Always include a ModalHeader with a descriptive title for aria-labelledby.
- Use ModalBody for scrollable content and ModalFooter for action buttons.
- Provide a visible close button inside ModalHeader.

**Don't:**

- Do not open a modal from inside another modal.
- Do not use modals for simple confirmations — use a compact dialog with clear action labels.
- Do not disable closeOnEscape without providing another keyboard-accessible close mechanism.

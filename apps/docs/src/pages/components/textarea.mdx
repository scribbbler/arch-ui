# Textarea

<span class="status-badge status-badge--stable">stable</span>

A multi-line text input component. Mirrors the ARIA integration of Input: when placed inside a FormControl it inherits id, required, disabled, and invalid state. Supports rows, resize behaviour, an autoResize mode that grows with content, and three size variants.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `rows` | `number` | `3` | The initial visible number of text lines. Has no effect when autoResize is true and the content is taller. |
| `resize` | `'none' \| 'vertical' \| 'both'` | `vertical` | Controls the CSS resize handle. Set to 'none' when autoResize is true. |
| `autoResize` | `boolean` | `false` | When true, the textarea grows to fit its content on every input event by setting its height to its scrollHeight. Automatically overrides resize to 'none' in CSS. Does not shrink below the initial rows height. |
| `clearable` | `boolean` | `false` | When true, shows a clear button (×) when the textarea has content. |
| `positive` | `boolean` | `false` | Shows a positive (success/valid) border style using color-border-success. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `md` | Controls padding and font size. Mirrors the Input size tokens. |
| `disabled` | `boolean` | `false` | Disables the textarea. Also inherited from FormControl context. |
| `readOnly` | `boolean` | `false` | Makes the textarea read-only. |
| `className` | `string` | `undefined` | Additional CSS class names applied to the textarea element. |
## Accessibility

**Role:** `textbox`

**ARIA attributes:** `aria-required`, `aria-disabled`, `aria-invalid`, `aria-describedby`, `aria-multiline`

**Keyboard interaction:**

- Tab
- Shift+Tab
- Enter (newline)

**Notes:**

- aria-multiline is implicitly true for &lt;textarea&gt;.
- When used inside a FormControl, the textarea's id is set to the context id so FormLabel's htmlFor links correctly.
- aria-describedby is automatically built from '&#123;id&#125;-helper' and/or '&#123;id&#125;-error' when inside a FormControl.
- aria-required is set when the FormControl is required.
- aria-invalid is set when the FormControl is invalid.
- Focus indicator uses a 2px solid outline with var(--color-border-focus) and a 2px offset.
- Minimum touch target is met for md and lg sizes.

## Usage Guidelines

**Do:**

- Always pair with a FormLabel (via FormControl) to provide an accessible name.
- Use autoResize for chat or note-taking contexts where variable-length input is expected.
- Set resize='none' when the Textarea is inside a fixed-height layout container.
- Use rows to set a meaningful default height that indicates expected input length.

**Don't:**

- Do not use autoResize and a fixed rows value as the sole height constraint — provide a max-height via a wrapper if needed.
- Do not omit a label — if no visible label, provide aria-label directly.
- Do not use inline styles to set height — use autoResize or rows.

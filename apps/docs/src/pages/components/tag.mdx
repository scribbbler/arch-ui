# Tag

<span class="status-badge status-badge--stable">stable</span>

A removable, categorisation label. Supports an optional leading icon slot and an optional close button for removal. Built for use in tag inputs, filter chips, and multi-select displays.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `'neutral' \| 'primary' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `neutral` | Colour palette variant of the tag. |
| `onRemove` | `() =&gt; void` | `undefined` | When provided, renders a close button that triggers this callback (unless closeable is false). The button receives aria-label='Remove &#123;children&#125;'. |
| `closeable` | `boolean` | `true (when onRemove provided)` | Whether the close button is visible when onRemove is provided. Set to false to hide the close button. |
| `clickable` | `boolean` | `false` | When true, the tag behaves as a toggle chip. The tag becomes clickable and receives role='option' and tabIndex=0. |
| `isChecked` | `boolean` | `false` | Whether the tag is currently in a checked/selected state. Only relevant when clickable is true. Controls aria-selected and visual checked style. |
| `icon` | `ReactNode` | `undefined` | An optional icon rendered at the inline-start of the label. |
| `children` | `ReactNode` | `—` | The label content of the tag. |
| `className` | `string` | `undefined` | Additional CSS class names to apply to the root element. |
## Accessibility

**Role:** `generic`

**ARIA attributes:** `aria-label`

**Keyboard interaction:**

- Tab
- Enter
- Space
- Delete
- Backspace

**Notes:**

- The remove button receives aria-label='Remove &#123;children&#125;' to clearly communicate its action.
- The icon slot is aria-hidden to prevent redundant announcements.
- When onRemove is provided, the close button is focusable and keyboard-operable.

## Usage Guidelines

**Do:**

- Use tags to represent user-selected filter values or categories.
- Provide onRemove when the tag should be dismissible.
- Keep tag labels concise — one to three words.

**Don't:**

- Do not use tags for navigation — use links instead.
- Do not nest interactive elements inside a tag beyond the close button.
- Do not use tags as the only mechanism to communicate a state — pair with text.

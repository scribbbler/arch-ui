# SkipNav

<span class="status-badge status-badge--stable">stable</span>

Skip-to-main-content link that appears on first tab press. Must be the first focusable element in the document. Required for keyboard accessibility.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `targetId` | `string` | `main-content` | The id of the main content element to skip to. Default: 'main-content'. |
| `children` | `React.ReactNode` | `undefined` | Link text. Takes precedence over labels.skipToContent. |
| `labels` | `Partial&lt;SkipNavLabels&gt;` | `&#123; skipToContent: 'Skip to main content' &#125;` | Override default labels for internationalisation. SkipNavLabels: &#123; skipToContent: string &#125;. The children prop takes precedence over labels.skipToContent. |

## Usage Guidelines

**Do:**

- Place SkipNav as the very first child of &lt;body&gt; or your root layout
- Ensure the target element has a matching id attribute
- Test by pressing Tab on page load — the link should be the first thing that appears

**Don't:**

- Do not hide SkipNav with display:none — it must be focusable
- Do not place it inside a navigation or header — it goes before those

# Checkbox

<span class="status-badge status-badge--stable">stable</span>

A checkbox input component that renders a real &lt;input type="checkbox"&gt; for accessibility, with a custom-styled visual overlay. Supports checked, indeterminate, disabled, and error states.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `checked` | `boolean` | `false` | Whether the checkbox is checked. |
| `indeterminate` | `boolean` | `false` | Whether the checkbox is in an indeterminate state. Overrides checked visually. Sets aria-checked to 'mixed'. |
| `disabled` | `boolean` | `false` | Disables the checkbox. Prevents interaction and reduces visual emphasis. |
| `isError` | `boolean` | `false` | Shows an error state. Border colour changes to var(--color-border-danger). |
| `onChange` | `(e: React.ChangeEvent&lt;HTMLInputElement&gt;) =&gt; void` | `undefined` | Called when the checked state changes. |
| `children` | `ReactNode` | `—` | Label content rendered next to the checkbox. |
| `labelPlacement` | `'end' \| 'start' \| 'top' \| 'bottom'` | `end` | Position of the label relative to the checkbox visual. 'end' places the label after the checkbox (inline-end); 'start' places it before; 'top' places it above; 'bottom' places it below. |
| `className` | `string` | `undefined` | Additional CSS class names to apply to the wrapper element. |
## Accessibility

**Role:** `checkbox`

**ARIA attributes:** `aria-checked`, `aria-disabled`, `aria-invalid`

**Keyboard interaction:**

- Space

**Notes:**

- A real &lt;input type="checkbox"&gt; is rendered and visually hidden; the styled box is a presentation layer.
- The indeterminate state is set via the indeterminate DOM property and aria-checked="mixed".
- Focus indicator appears on the visual checkbox via :focus-visible using var(--color-border-focus).
- When isError is true, the border uses var(--color-border-danger).
- The label is associated with the input via htmlFor/id pairing.
- Touch target is at minimum 44×44px via min-block-size and min-inline-size on the wrapper.

## Usage Guidelines

**Do:**

- Always provide visible label text as children, or an aria-label if no children.
- Use indeterminate for parent checkboxes in a tree/group that are partially selected.
- Use isError alongside a visible error message to communicate validation failures.
- Group multiple checkboxes inside a CheckboxGroup with a legend.

**Don't:**

- Do not use indeterminate as a substitute for an unchecked state.
- Do not leave a checkbox without an associated label.
- Do not use for mutually exclusive choices — use RadioGroup instead.

# Toggle

<span class="status-badge status-badge--stable">stable</span>

A binary on/off switch rendered as a styled checkbox with role='switch'. The thumb position (not colour alone) communicates the checked state. Integrates with FormControl context to receive id, disabled, and required state automatically.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `checked` | `boolean` | `undefined` | Whether the toggle is in the on (checked) state. Use with onChange for controlled usage. |
| `defaultChecked` | `boolean` | `false` | Initial checked state for uncontrolled usage. |
| `disabled` | `boolean` | `false` | Disables the toggle. Also inherited from FormControl context if not explicitly set. |
| `onChange` | `(e: React.ChangeEvent&lt;HTMLInputElement&gt;) =&gt; void` | `undefined` | Callback fired when the checked state changes. |
| `children` | `ReactNode` | `undefined` | Optional label text rendered beside the track. |
| `size` | `'xs' \| 'sm' \| 'md'` | `md` | Size variant. xs renders the smallest track for very dense UIs; sm renders a narrower track; md meets the 44px touch-target minimum. |
| `className` | `string` | `undefined` | Additional CSS class names applied to the outermost wrapper element. |
## Accessibility

**Role:** `switch`

**ARIA attributes:** `aria-checked`, `aria-disabled`, `aria-required`, `aria-label`, `aria-labelledby`

**Keyboard interaction:**

- Space
- Tab
- Shift+Tab

**Notes:**

- The underlying input has type='checkbox' and role='switch' — assistive technology announces on/off state via aria-checked.
- Thumb position is the primary non-color indicator: off = inline-start, on = inline-end.
- Focus indicator is a 2px solid outline on the track using var(--color-border-focus) with a 2px offset.
- Disabled state reduces opacity and sets cursor: not-allowed.
- prefers-reduced-motion is respected — transition is disabled when the user has opted out of motion.
- Touch target meets 44x44px minimum for the md size via min-block-size on the label wrapper.

## Usage Guidelines

**Do:**

- Always provide a visible label (children) or aria-label so the toggle has an accessible name.
- Use inside a FormControl when the toggle is part of a labelled form field group.
- Use size='sm' only in dense UIs such as settings panels with many options.

**Don't:**

- Do not use a Toggle for multi-step choices — use a Checkbox group or Radio group instead.
- Do not rely on colour alone to communicate state — the thumb position must also signal on/off.
- Do not apply inline styles — use the className prop and extend via CSS tokens.

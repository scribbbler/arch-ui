# Portal

<span class="status-badge status-badge--stable">stable</span>

Renders children into a DOM node outside the current React tree using createPortal. Defaults to document.body; accepts a custom container element.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | `—` | Content to teleport into the target container. |
| `container` | `HTMLElement \| null` | `null` | Target DOM element to render children into. Defaults to document.body when null. |
## Accessibility

**Notes:**

- Portal does not add any ARIA attributes itself.
- Content rendered inside a Portal must manage its own accessible roles and attributes.
- Portals do not affect the React event bubbling order — events still bubble through the React tree.

## Usage Guidelines

**Do:**

- Use Portal as the rendering layer for overlays, tooltips, modals, and drawers.
- Pass a custom container when you need to scope the portal within a specific DOM subtree.

**Don't:**

- Do not rely on Portal for z-index stacking — manage that with z-index tokens on the content.
- Do not render portals during server-side rendering without a defined container.

# Inline

<span class="status-badge status-badge--stable">stable</span>

Horizontal flex layout with token-based gap. Children are laid out horizontally and wrap naturally.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `gap` | `string` | `—` | Spacing token name for gap between children |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'` | `center` | Cross-axis alignment (maps to align-items) |
| `justify` | `'start' \| 'center' \| 'end' \| 'space-between'` | `start` | Main-axis alignment (maps to justify-content) |
| `wrap` | `boolean` | `true` | Whether children wrap to next line. Default: true. |
| `as` | `React.ElementType` | `div` | HTML element to render. Default: 'div'. |
| `children` | `React.ReactNode` | `—` |  |

## Usage Guidelines

**Do:**

- Use Inline for horizontal layouts like button groups, tag lists, icon + text
- Inline wraps by default — this is intentional for responsive layouts

**Don't:**

- Do not use Inline for vertical layouts — use Stack instead
- Do not disable wrap unless you are certain the content will fit

# Icons

The `@arch-ui/icons` package provides 43 SVG icons as React components. All icons are stroke-based, use `currentColor` by default, and are accessible out of the box.

## Installation

```bash
pnpm add @arch-ui/icons
```

## Usage

```tsx
import { SearchIcon, PlusIcon, TrashIcon } from '@arch-ui/icons';

<SearchIcon />
<PlusIcon size={24} />
<TrashIcon aria-label="Delete item" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `16 \| 20 \| 24` | `20` | Icon size in pixels |
| `color` | `string` | `currentColor` | Stroke color |
| `aria-label` | `string` | -- | Accessible label for standalone icons |
| `rtl` | `boolean` | `false` | Flip horizontally in RTL layouts |

## Color and Size Inheritance

Icons use `currentColor` by default, so they inherit the text color of their parent element. Set color on the parent or use the semantic icon tokens:

```css
.icon-container {
  color: var(--color-icon-default);
}

.icon-container--danger {
  color: var(--color-icon-danger);
}
```

## Accessibility

- **Decorative icons** (next to text): No `aria-label` needed. The icon renders with `aria-hidden="true"` by default.
- **Standalone icons** (no adjacent text): Provide `aria-label` so screen readers announce the purpose. This also sets `role="img"`.

```tsx
{/* Decorative -- label is in the button text */}
<button>
  <PlusIcon /> Add item
</button>

{/* Standalone -- needs aria-label */}
<button>
  <TrashIcon aria-label="Delete" />
</button>
```

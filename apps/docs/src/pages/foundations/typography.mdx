# Typography

The Arch type system follows the Uber Base Web typography scale. Each category has a fixed font weight — no weight prop is needed.

## Font Families

| Token | Stack |
|-------|-------|
| `--typography-family-sans` | 'Inter', system-ui, -apple-system, sans-serif |
| `--typography-family-mono` | ui-monospace, SFMono-Regular, 'SF Mono', Menlo, Consolas, monospace |
| `--typography-family-serif` | Georgia, Cambria, 'Times New Roman', Times, serif |

## Type Scale

Four categories, each with a fixed weight:

### Display — bold (700)

For page titles, hero sections, and marketing content.

| Scale | Font size | Line height |
|-------|-----------|-------------|
| `display-large` | 96px | 112px |
| `display-medium` | 52px | 64px |
| `display-small` | 44px | 52px |
| `display-xsmall` | 36px | 44px |

### Heading — bold (700)

For section headings. Maps to h1–h6.

| Scale | Font size | Line height | Default level |
|-------|-----------|-------------|---------------|
| `heading-xxlarge` | 40px | 52px | h1 |
| `heading-xlarge` | 36px | 44px | h2 |
| `heading-large` | 32px | 40px | h3 |
| `heading-medium` | 28px | 36px | h4 |
| `heading-small` | 24px | 32px | h5 |
| `heading-xsmall` | 20px | 28px | h6 |

### Label — medium (500)

For UI text: form labels, button text, navigation items, badges, table headers.

| Scale | Font size | Line height |
|-------|-----------|-------------|
| `label-large` | 18px | 24px |
| `label-medium` | 16px | 20px |
| `label-small` | 14px | 16px |
| `label-xsmall` | 12px | 16px |

### Paragraph — regular (400)

For body copy, descriptions, and long-form reading.

| Scale | Font size | Line height |
|-------|-----------|-------------|
| `paragraph-large` | 18px | 28px |
| `paragraph-medium` | 16px | 24px |
| `paragraph-small` | 14px | 20px |
| `paragraph-xsmall` | 12px | 20px |

### Code

| Scale | Font size | Line height |
|-------|-----------|-------------|
| `code-md` | 14px | 20px |
| `code-sm` | 12px | 20px |

## Using Scale Tokens

Each scale token exposes four sub-properties:

```css
.my-heading {
  font-size: var(--typography-scale-heading-large-font-size);
  line-height: var(--typography-scale-heading-large-line-height);
  font-weight: var(--typography-scale-heading-large-font-weight);
  letter-spacing: var(--typography-scale-heading-large-letter-spacing);
}
```

## Components

| Component | Category | Default size |
|-----------|----------|-------------|
| `Display` | Display | `large` |
| `Heading` | Heading | Maps to level (h1=xxlarge, h6=xsmall) |
| `Label` | Label | `medium` |
| `Paragraph` | Paragraph | `medium` |
| `Code` | Code | `md` |

```tsx
<Display size="medium">Hero Title</Display>
<Heading level={2}>Section Title</Heading>
<Label size="small">Field Label</Label>
<Paragraph>Body text content here.</Paragraph>
<Code variant="block">const x = 1;</Code>
```

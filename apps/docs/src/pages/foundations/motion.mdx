# Motion

Motion tokens define duration and easing for animations and transitions. Arch provides both primitive values and semantic aliases.

## Duration Tokens

### Primitive

| Token | Value | Use for |
|-------|-------|---------|
| `--motion-duration-instant` | 0ms | Immediate state changes |
| `--motion-duration-fast` | 100ms | Micro-interactions (hover, focus) |
| `--motion-duration-normal` | 200ms | Standard transitions (color, opacity) |
| `--motion-duration-slow` | 300ms | Expanding/collapsing content |
| `--motion-duration-slower` | 500ms | Complex layout animations |

### Semantic

| Token | Resolves to |
|-------|------------|
| `--motion-semantic-duration-instant` | 0ms |
| `--motion-semantic-duration-fast` | 100ms |
| `--motion-semantic-duration-normal` | 200ms |
| `--motion-semantic-duration-slow` | 300ms |
| `--motion-semantic-duration-slower` | 500ms |

## Easing Tokens

### Primitive

| Token | Value |
|-------|-------|
| `--motion-easing-linear` | linear |
| `--motion-easing-ease-in` | cubic-bezier(0.4, 0, 1, 1) |
| `--motion-easing-ease-out` | cubic-bezier(0, 0, 0.2, 1) |
| `--motion-easing-ease-in-out` | cubic-bezier(0.4, 0, 0.2, 1) |
| `--motion-easing-spring` | cubic-bezier(0.175, 0.885, 0.32, 1.275) |
| `--motion-easing-bounce` | cubic-bezier(0.68, -0.55, 0.265, 1.55) |

### Semantic

| Token | Resolves to | Use for |
|-------|------------|---------|
| `--motion-semantic-easing-default` | ease-in-out | General transitions |
| `--motion-semantic-easing-enter` | ease-out | Elements appearing (fade in, slide in) |
| `--motion-semantic-easing-exit` | ease-in | Elements leaving (fade out, slide out) |

## Usage

```css
.tooltip {
  transition: opacity var(--motion-semantic-duration-fast) var(--motion-semantic-easing-enter);
}

.accordion-content {
  transition: height var(--motion-semantic-duration-slow) var(--motion-semantic-easing-default);
}
```

## Reduced Motion

All Arch components respect `prefers-reduced-motion`. When the user has requested reduced motion, animations are either removed or replaced with instant transitions.

Apply this pattern in component CSS:

```css
.animated-element {
  transition: transform var(--motion-semantic-duration-normal) var(--motion-semantic-easing-default);
}

@media (prefers-reduced-motion: reduce) {
  .animated-element {
    transition: none;
  }
}
```

Every component in the system must honor this media query. Animations that convey state changes should fall back to instant opacity or visibility changes rather than being fully removed, so the state change is still communicated.

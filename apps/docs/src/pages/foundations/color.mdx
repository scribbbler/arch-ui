# Color

The Arch color system is built from primitive color scales that feed into semantic tokens. Components only use semantic tokens, making theme switching (including dark mode) possible without changing component code.

## Primitive Scales

Eight color scales plus black and white. Each scale runs from `50` (lightest) to `950` (darkest).

| Scale | Token pattern | Example |
|-------|--------------|---------|
| Gray | `--color-gray-{50-950}` | `var(--color-gray-600)` |
| Blue | `--color-blue-{50-950}` | `var(--color-blue-600)` |
| Green | `--color-green-{50-950}` | `var(--color-green-500)` |
| Red | `--color-red-{50-950}` | `var(--color-red-600)` |
| Yellow | `--color-yellow-{50-950}` | `var(--color-yellow-500)` |
| Orange | `--color-orange-{50-950}` | `var(--color-orange-500)` |
| Purple | `--color-purple-{50-950}` | `var(--color-purple-600)` |
| Teal | `--color-teal-{50-950}` | `var(--color-teal-500)` |

Steps per scale: `50`, `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`, `950`.

## Semantic Tokens

Use these in components instead of primitives.

### Background

| Token | Light value | Purpose |
|-------|------------|---------|
| `--color-background-default` | white | Page/component background |
| `--color-background-subtle` | gray-50 | Slightly tinted background |
| `--color-background-muted` | gray-100 | Muted areas |
| `--color-background-inverse` | gray-900 | Inverted backgrounds |
| `--color-background-disabled` | gray-100 | Disabled controls |
| `--color-background-overlay` | rgba(0,0,0,0.5) | Modal overlays |

## Dark Mode

Dark mode is handled entirely through token overrides. The same semantic token names resolve to different primitive values. For example:

| Token | Light | Dark |
|-------|-------|------|
| `--color-background-default` | white | gray-900 |
| `--color-text-default` | gray-900 | gray-50 |
| `--color-action-primary` | blue-600 | blue-500 |
| `--color-border-default` | gray-200 | gray-700 |
| `--color-surface-raised` | white | gray-800 |

Components do not need any conditional logic for dark mode. The token layer handles the swap. Dark overrides are defined in `packages/tokens/src/semantic/color-dark.json`.

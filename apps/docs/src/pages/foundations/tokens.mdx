# Design Tokens

Arch UI uses a three-layer token architecture. Every visual value in the system flows through tokens, exposed as CSS custom properties via `var(--token-name)`. No component ever uses a raw hex, pixel, or named color directly.

## Three-Layer Architecture

### 1. Primitive Tokens

Raw values with no semantic meaning. These are the building blocks -- color scales, spacing numbers, font sizes.

```css
/* Examples */
var(--color-blue-600)    /* #2563eb */
var(--spacing-16)        /* 16px */
var(--typography-size-14) /* 14px */
```

Primitives live in `packages/tokens/src/primitive/` and should never be used directly in component CSS. They exist only to be referenced by semantic tokens.

### 2. Semantic Tokens

Intent-based aliases that describe *what* a value is used for, not *what* it is. These are the tokens you use in component styles.

```css
/* Examples */
var(--color-text-default)       /* References gray-900 in light mode */
var(--color-action-primary)     /* References blue-600 */
var(--spacing-component-md)     /* References spacing-12 */
var(--motion-semantic-easing-default) /* ease-in-out */
```

Semantic tokens live in `packages/tokens/src/semantic/` and can be swapped per theme (e.g., dark mode) without changing component code.

### 3. Component Tokens

Per-component tokens that reference semantic tokens. These allow fine-grained control over individual components.

```css
/* Example: Button-specific tokens */
var(--button-bg)          /* References color-action-primary */
var(--button-padding-x)   /* References spacing-component-lg */
```

## Usage

Always use `var(--token-name)` in your CSS. Never hardcode values.

```css
/* Correct */
.my-element {
  color: var(--color-text-default);
  padding: var(--spacing-component-md);
  font-size: var(--typography-scale-text-md-font-size);
}

/* Incorrect -- never do this */
.my-element {
  color: #111827;
  padding: 12px;
  font-size: 15px;
}
```

## Token Categories

- [Color](/foundations/color) -- background, text, action, border, feedback, surface, and icon colors
- [Typography](/foundations/typography) -- font families, size scale, weights, and composite type scales
- [Spacing](/foundations/spacing) -- primitive scale and semantic spacing for components, inline, and layout
- [Motion](/foundations/motion) -- duration and easing tokens for animation

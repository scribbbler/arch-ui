# Grid

The `Grid` component provides CSS Grid layout with responsive column support powered by container queries.

## Basic Usage

```tsx
import { Grid } from '@arch-ui/components';

<Grid columns={3} gap="spacing-component-lg">
  <div>Column 1</div>
  <div>Column 2</div>
  <div>Column 3</div>
</Grid>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `columns` | `number \| 'auto' \| ResponsiveColumns` | `1` | Number of columns (1-12), `'auto'`, or responsive object |
| `gap` | `string` | -- | Spacing token name for gap (e.g., `"spacing-component-md"`) |
| `rowGap` | `string` | -- | Spacing token name for row gap |
| `colGap` | `string` | -- | Spacing token name for column gap |
| `as` | `ElementType` | `"div"` | HTML element to render |
| `className` | `string` | -- | Additional CSS class |

## Fixed Columns

Pass a number for a fixed column count.

```tsx
<Grid columns={2} gap="spacing-component-lg">
  <div>Left</div>
  <div>Right</div>
</Grid>

<Grid columns={4} gap="spacing-component-md">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
</Grid>
```

## Auto-fill Columns

Use `'auto'` for a fluid grid that fills columns based on available space (minimum 200px per column).

```tsx
<Grid columns="auto" gap="spacing-component-lg">
  <div>Card</div>
  <div>Card</div>
  <div>Card</div>
  <div>Card</div>
  <div>Card</div>
</Grid>
```

## Responsive Columns

Pass an object to define columns at different container widths. The grid uses container queries, so breakpoints respond to the grid's own width rather than the viewport.

```tsx
<Grid
  columns={{ base: 1, sm: 2, md: 3, lg: 4 }}
  gap="spacing-component-lg"
>
  <div>Item</div>
  <div>Item</div>
  <div>Item</div>
  <div>Item</div>
</Grid>
```

### Container Query Breakpoints

| Key | Min width |
|-----|-----------|
| `base` | 0px |
| `sm` | 480px |
| `md` | 768px |
| `lg` | 1024px |
| `xl` | 1280px |

## Separate Row and Column Gaps

Use `rowGap` and `colGap` for different horizontal and vertical spacing.

```tsx
<Grid
  columns={3}
  rowGap="spacing-layout-content-gap"
  colGap="spacing-component-md"
>
  <div>Item</div>
  <div>Item</div>
  <div>Item</div>
  <div>Item</div>
  <div>Item</div>
  <div>Item</div>
</Grid>
```

## Semantic Element

Use the `as` prop to render the grid as a different HTML element.

```tsx
<Grid as="ul" columns={3} gap="spacing-component-md">
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</Grid>
```

## Container Queries

The Grid component sets `container-type: inline-size` on itself. This means responsive breakpoints are based on the grid container's width, not the viewport. Grids nested inside sidebars or panels will adapt to their actual available space.

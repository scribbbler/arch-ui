# RTL Support

Arch components support right-to-left layouts natively. No JavaScript, no wrapper components, no extra props.

## Enable RTL

Set `dir="rtl"` on the `<html>` element:

```html
<html dir="rtl" lang="ar">
```

Every component mirrors automatically.

## How it works

All components use CSS logical properties instead of physical ones:

| Physical (not used) | Logical (used everywhere) |
|---|---|
| `margin-left` | `margin-inline-start` |
| `padding-right` | `padding-inline-end` |
| `border-left` | `border-inline-start` |
| `text-align: left` | `text-align: start` |

When the document direction changes, `inline-start` and `inline-end` flip automatically. No conditional styles, no mirrored stylesheets.

## Scoped direction

You can set direction on any container:

```html
<div dir="rtl">
  <!-- This section renders right-to-left -->
</div>
```

This is useful for multilingual interfaces where some sections use a different script direction.

## Icons

Icons that have a directional meaning (arrows, chevrons) respond to `dir` automatically via CSS `transform` on `[dir="rtl"]`. Symmetrical icons like checkmarks and close buttons remain unchanged.

## Testing RTL

The simplest way to verify your layout:

1. Add `dir="rtl"` to `<html>`
2. Check that text, padding, and icons mirror correctly
3. Confirm that reading order flows right-to-left
4. Remove `dir="rtl"` and verify the layout returns to LTR

No build step or configuration changes are needed.

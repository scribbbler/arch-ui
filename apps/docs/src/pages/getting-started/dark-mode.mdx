# Dark Mode

Arch supports dark mode out of the box. Set a single data attribute and every component adapts.

## Enable dark mode

Add `data-theme="dark"` to the `<html>` element:

```html
<html data-theme="dark">
```

That's it. All 51 components respond automatically because they reference semantic tokens, and the token stylesheet ships with dark-mode overrides scoped to `[data-theme="dark"]`.

## Toggle at runtime

```tsx
function ThemeToggle() {
  const toggle = () => {
    const html = document.documentElement;
    const next = html.dataset.theme === 'dark' ? 'light' : 'dark';
    html.dataset.theme = next;
  };

  return <button onClick={toggle}>Toggle theme</button>;
}
```

## Scoped dark mode

You can apply dark mode to any container, not just the root:

```html
<div data-theme="dark">
  <!-- These components render in dark mode -->
</div>
```

This is useful for surfaces like slide-out panels or preview panes that should always be dark regardless of the page theme.

## How it works

The token stylesheet defines two sets of semantic values:

```css
/* Light (default) */
:root {
  --color-bg-surface: #ffffff;
  --color-text-primary: #1a1a1a;
}

/* Dark */
[data-theme="dark"] {
  --color-bg-surface: #1a1a1a;
  --color-text-primary: #f5f5f5;
}
```

Components bind to `--color-bg-surface` and `--color-text-primary`, so they swap appearance without any class or prop changes.

## Respecting system preference

If you want to follow the operating system setting by default:

```js
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
document.documentElement.dataset.theme = prefersDark ? 'dark' : 'light';
```

Combine this with the toggle above to let users override the system preference.

# Installation

Get Arch UI running in your project in under two minutes.

## 1. Install packages

```bash
pnpm add @arch-ui/components @arch-ui/tokens
```

If you only need tokens (for non-React projects), install `@arch-ui/tokens` alone.

## 2. Import the token stylesheet

Add this import once at the root of your application, before any component CSS:

```ts
import '@arch-ui/tokens/css';
```

This injects all CSS custom properties (`--color-*`, `--spacing-*`, `--typography-*`, etc.) into `:root`.

## 3. Load the Inter font

Add to your HTML `&lt;head&gt;` or use fontsource:

```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap" rel="stylesheet">
```

## 4. Use a component

```tsx
import &#123; Button &#125; from '@arch-ui/components';

function App() &#123;
  return (
    &lt;Button kind="primary" onClick=&#123;() =&gt; alert('It works!')&#125;&gt;
      Get started
    &lt;/Button&gt;
  );
&#125;
```

## 5. Optional: install icons

```bash
pnpm add @arch-ui/icons
```

Icons are sourced from Material Design Icons (MDI).

```tsx
import &#123; CheckIcon &#125; from '@arch-ui/icons';

&lt;Button kind="primary" startEnhancer=&#123;&lt;CheckIcon /&gt;&#125;&gt;Confirm&lt;/Button&gt;
```

## What you get

| Package | Contents |
|---|---|
| `@arch-ui/tokens` | 400+ CSS custom properties — colors (Uber Base palette), typography, spacing, shadows |
| `@arch-ui/components` | 50 React components with full a11y and RTL support |
| `@arch-ui/icons` | 43 Material Design Icons with React wrappers |

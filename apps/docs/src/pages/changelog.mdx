# Changelog

All notable changes to the Arch Design System are documented here.

---

## v0.2.0

**2026-04-04** — Base Web alignment

### Breaking changes

- **Button**: `variant` renamed to `kind`. Values: primary, secondary, tertiary, dangerPrimary, dangerSecondary, dangerTertiary.
- **Button**: `leftIcon`/`rightIcon` renamed to `startEnhancer`/`endEnhancer`.
- **Button**: `loading` renamed to `isLoading`.
- **Button**: Size values changed from sm/md/lg to mini/compact/default/large.
- **IconButton**: Removed. Use `Button shape="circle"` or `shape="square"` with `startEnhancer` instead.
- **Typography**: Scale names changed. display-2xl→display-large, text-sm→paragraph-small/label-small, etc. Weight props removed — weight is fixed per category.
- **Input/Select/Textarea**: Size values changed to mini/compact/default/large.

### New features

- Button: shape prop (default, pill, circle, square), isSelected prop.
- Input/Textarea: clearable and positive props.
- Modal: role prop (dialog/alertdialog), animate prop.
- Popover: showArrow, triggerType (click/hover), mouse delay props.
- Tabs: artwork (icon slot), fill (fixed/intrinsic), renderAll.
- Accordion: disabled (root + per-item), onChange callback, ReactNode titles.
- Toast: closeable, pauseOnHover, all 6 positions.
- Badge: placement for overlay positioning.
- Tag: clickable chip mode with isChecked.
- Pagination: size and shape props.
- Link: animateUnderline prop.

### Foundation

- Color palette updated to match Uber Base exactly (11 scales including magenta, lime, amber).
- Typography scale aligned to Base Web (Display/Heading/Label/Paragraph categories).
- Shadows updated to Base Web elevation system.
- Spacing uses direct tokens (var(--spacing-8)) matching Base Web sizing scale.
- Icons replaced with Material Design Icons (@mdi/svg).
- Inter font as default sans-serif.

## v0.1.0

**2026-04-02** — Initial release

Initial release with 51 components, 336 tokens, MCP server, Storybook, and documentation site.

### Packages

- **@arch-ui/tokens** — Design tokens built with Style Dictionary v4.
- **@arch-ui/components** — React components with full keyboard navigation and ARIA support.
- **@arch-ui/icons** — SVG icons with React wrappers.
- **@arch-ui/mcp-server** — MCP server for AI agent consumption.

### Highlights

- All components use CSS custom properties — no hardcoded values.
- FormControl context system wires labels, inputs, and errors via shared ARIA IDs.
- Toast system with imperative `useToast` hook.
- Full keyboard navigation for Tabs, Pagination, RadioGroup, and Modal.
- `prefers-reduced-motion` support across all animated components.

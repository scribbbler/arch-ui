## Principles

### Actionable
Buttons should trigger a clear action. Every button needs a verb — "Save", "Delete", "Continue" — not just "OK" or "Submit".

### Hierarchical
Use button kinds to establish visual hierarchy. One `primary` per section, supported by `secondary` and `tertiary`.

### Consistent
Buttons across the product should use the same sizes, kinds, and patterns. Don't mix custom styles.

## When to Use

- Triggering an action (save, submit, delete)
- Navigating when styled as a link (`as="a"`)
- Toggle selection in a ButtonGroup

## When Not to Use

- **For navigation** — use Link instead
- **For toggling states** — use Toggle/Switch instead
- **Inside another button** — never nest interactive elements

## Anatomy

```
┌─────────────────────────────────────────┐
│  [startEnhancer]  [label]  [endEnhancer] │
└─────────────────────────────────────────┘
```

| Part | Description |
|------|-------------|
| **startEnhancer** | Optional icon before the label |
| **label** | Text content via `children` |
| **endEnhancer** | Optional icon after the label |

For icon-only buttons, use `shape="circle"` or `shape="square"` with only `startEnhancer` and no children. Always provide `aria-label`.

## Kinds

| Kind | Use for | Example |
|------|---------|---------|
| `primary` | Main action. One per section. | Save, Continue, Submit |
| `secondary` | Supporting actions. | Cancel, Back |
| `tertiary` | Low-emphasis actions. | Learn more, Skip |
| `dangerPrimary` | Destructive actions. | Delete account |
| `dangerSecondary` | Destructive, less prominent. | Remove item |
| `dangerTertiary` | Destructive, minimal. | Unsubscribe |

## Sizes

| Size | Height | Font | Use case |
|------|--------|------|----------|
| `mini` | 28px | Label XSmall (12px) | Dense UI, table row actions |
| `compact` | 36px | Label Small (14px) | Toolbars, inline actions |
| `default` | 48px | Label Medium (16px) | Standard forms and pages |
| `large` | 56px | Label Large (18px) | Hero CTAs, prominent actions |

## Shapes

| Shape | Radius | Use case |
|-------|--------|----------|
| `default` | 8px | Standard buttons |
| `pill` | 9999px | Softer, rounded style |
| `circle` | 50%, fixed dims | Icon-only, round |
| `square` | 4px, fixed dims | Icon-only, sharp |

:::tip Do
- Use `primary` for the single most important action on the page
- Pair with `secondary` or `tertiary` for supporting actions
- Always provide visible text — icon-only buttons need `aria-label`
- Use `isLoading` with `loadingText` so users know what's happening
:::

:::danger Don't
- Don't use multiple `primary` buttons in the same section
- Don't use `dangerPrimary` for non-destructive actions
- Don't disable buttons without explaining why (use tooltip)
- Don't put interactive elements inside a button
- Don't use `shape="circle"` with text content
:::

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `kind` | `'primary' \| 'secondary' \| 'tertiary' \| 'dangerPrimary' \| 'dangerSecondary' \| 'dangerTertiary'` | `'primary'` | Visual style |
| `size` | `'mini' \| 'compact' \| 'default' \| 'large'` | `'default'` | Height and font |
| `shape` | `'default' \| 'pill' \| 'circle' \| 'square'` | `'default'` | Border radius |
| `isSelected` | `boolean` | `false` | Toggle state |
| `disabled` | `boolean` | `false` | Prevents interaction |
| `isLoading` | `boolean` | `false` | Shows spinner |
| `loadingText` | `string` | — | Label during loading |
| `startEnhancer` | `ReactNode` | — | Icon before label |
| `endEnhancer` | `ReactNode` | — | Icon after label |
| `fullWidth` | `boolean` | `false` | 100% width |
| `as` | `ElementType` | `'button'` | Polymorphic element |

## States

| State | Visual | ARIA |
|-------|--------|------|

| Focus | Inset 2px ring | — |

## Writing Button Labels

- **Use verbs** — "Save changes", not "Changes"
- **Be specific** — "Delete account" instead of "Delete"
- **Stay concise** — 1–3 words for primary, up to 5 for secondary
- **Use sentence case** — "Save changes", not "Save Changes"

## Loading Text

When `isLoading` is true, replace the label with a present participle:
- "Save" → "Saving…"
- "Delete" → "Deleting…"
- "Submit" → "Submitting…"

## Icon Guidelines

- Icons should reinforce the label, not replace it (except icon-only buttons)
- Use `startEnhancer` for action icons (add, search, download)
- Use `endEnhancer` for directional icons (arrow right, external link)
